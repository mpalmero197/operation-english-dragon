# 05 — FBI Identity History Summary (EDO) Checklist

**Official free electronic channel:** https://www.edo.cjis.gov/  

This is the FBI’s **Identity History Summary** (often called a “police clearance” for overseas work). Use the government site only. No third-party paid “FBI agents” needed for this pack.

---

## Why you need it

Chinese Work Permit / Z visa employers almost always require a recent criminal background check from your home country, then authentication/apostille + sometimes translation.

---

## Before you start

- [ ] Valid government photo ID  
- [ ] Ability to get fingerprints (see options below)  
- [ ] Email you check daily  
- [ ] Soft copies storage folder on phone/computer  

---

## Step-by-step (EDO)

1. [ ] Go to https://www.edo.cjis.gov/ and read current instructions.  
2. [ ] Create / use **your own** EDO account (government site).  
3. [ ] Start an **Identity History Summary** request.  
4. [ ] Complete identity fields exactly as on passport.  
5. [ ] Submit fingerprints via an accepted method (below).  
6. [ ] Pay only the **FBI’s published fee** on the official site (this pack charges $0).  
7. [ ] Save confirmation number.  
8. [ ] When result is ready: **download and save PDF immediately**; keep multiple backups.  
9. [ ] Print on quality paper if authentication offices require hard copy.  
10. [ ] Proceed to **apostille / authentication** (see note below).  

---

## Fingerprints — common free/low-cost options

Check EDO’s current accepted formats. Typical options:

| Option | Notes |
|--------|-------|
| Local law enforcement | Call non-emergency line; ask if they ink/live-scan for FBI channeling |
| Approved channelers listed on FBI site | Some charge printing fees — optional |
| FD-1164 / card | Only if EDO instructions still allow mail-in cards |

- [ ] Confirm whether **electronic** channeling or **mail-in cards** are accepted for your request type  
- [ ] Get prints taken **clearly** (smudges cause rejection)  
- [ ] Keep receipt from fingerprint provider  

---

## What to save

- [ ] EDO confirmation / request ID  
- [ ] Payment receipt  
- [ ] Final Identity History Summary PDF  
- [ ] Printed hard copy (unlaminated)  
- [ ] Tracking numbers for any mail  

---

## Apostille / authentication after FBI result

FBI summaries are **federal** documents.

- [ ] Do **not** assume Tennessee SOS can apostille them  
- [ ] Check current **US Department of State** authentications / apostille guidance for federal documents  
- [ ] Ask your Chinese employer which form they need (apostille vs embassy legalization — China now generally uses apostille, but HR may still quote old rules)  
- [ ] After authentication: scan + pouch the original  

Education apostilles → TN SOS (`04-tn-apostille-packet.md`).  
FBI → confirm federal path first.

---

## Timing tip

Background checks **expire** for Chinese work-permit purposes (often ~6 months). Align FBI timing with:

1. Job offer / PU letter timeline  
2. Apostille turnaround  
3. Z visa appointment  

Don’t obtain it years early if it will go stale.
