# 09 — Coco Share One-Pager (weekly WeChat pulse)

Copy-paste into WeChat every week (Sunday night or Monday morning). Keep it short.

---

## Template (English)

```
周报 / Weekly pulse — Michael

✅ This week’s win:
[ one concrete thing done — e.g. “Ordered ITT transcripts on Parchment #______” ]

➡️ Next step:
[ one next action + target day — e.g. “Notary appointment Tue; then TN SOS packet” ]

❓ Need from you (optional):
[ blank / or one ask — e.g. “Confirm school still wants sealed envelope unopened” ]

❤️ Miss you / see you soon
```

---

## Template (中英 bilingual — optional)

```
本周进展 Weekly：
✅ 完成：[ ]
➡️ 下一步：[ ]（目标日期：____）
❓ 需要你帮忙：[无 / ……]
```

## Rules

- One win only (builds momentum)  
- One next step only (avoids overwhelm)  
- No dumping full checklists into chat  
- Update `01-document-inventory.md` privately after you send
