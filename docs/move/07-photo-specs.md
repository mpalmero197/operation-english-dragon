# 07 — China Visa / Work Permit Photo Specs

Take free photos with a phone + plain wall. Recheck embassy / employer specs before printing — rules can tweak.

---

## Typical China visa photo requirements (verify on current notice)

| Spec | Target |
|------|--------|
| Size | Often **48 mm × 33 mm** (visa) — confirm current COVA/embassy size |
| Work permit / residence | Often **2-inch** style (approx **33×48 mm** or local “小二寸”) — follow school HR |
| Color | Color photo |
| Background | **White** or very light plain (embassy usually white) |
| Head position | Full face, centered, eyes open, mouth closed |
| Expression | Neutral |
| Glasses | Prefer **no glasses** (no glare, no tint) |
| Headwear | None unless daily religious worn; full face visible |
| Recency | Taken within **last 6 months** |
| Quality | Sharp, not over/underexposed, no filters, no beauty mode that alters face |

---

## Free phone capture checklist

- [ ] Stand ~0.5–1 m from a **plain white wall** (no texture, no shadow)  
- [ ] Daylight or bright even light facing you (no window glare behind)  
- [ ] Camera at **eye level**; have someone else shoot or use timer  
- [ ] Shoulders visible; head ~70–80% of frame height  
- [ ] No selfie angle (distorts face)  
- [ ] Remove hats, headphones, AirPods  
- [ ] Turn off beauty filters / Portrait “smooth” if it changes skin or jaw  
- [ ] Take 10 shots; pick the sharpest  

---

## Crop & print (cheap / free DIY)

- [ ] Crop to required aspect ratio (use any free crop tool offline)  
- [ ] Print at pharmacy / library photo kiosk on glossy or photo paper as required  
- [ ] Cut carefully to exact mm size  
- [ ] Bring **extras** (visa + work permit + residence permit often need more)  

Suggested count to carry:

| Use | Prints |
|-----|--------|
| Z visa application | 2–3 |
| Work permit | 2–3 |
| Residence permit / CAN | 2–3 |
| Spares in pouch | 2 |

---

## Digital file

- [ ] Save a high-res JPEG (no watermark)  
- [ ] Filename example: `palmero-visa-photo-YYYYMM.jpg`  
- [ ] Upload only when COVA / employer portal asks  

---

## Reject reasons to avoid

- Shadow on background  
- Too much blank space above head / chin cut off  
- Red-eye or yellow cast  
- Over-smoothed skin  
- Wrong size paper cut
