**https://www.gzwbzx.com/**

- [ ] Employer or Coco confirm whether you book before or after first workday  
- [ ] Bring passport, photos, any forms school provides

## Address registration (with Coco)

Foreigners must register temporary residence with local police / via hotel or landlord process.

- [ ] Register within the required window after arrival (often **24 hours** if not in a hotel that does it for you — confirm current local rule)  
- [ ] Bring passport + Coco’s ID / lease / property docs as applicable  
- [ ] Keep the registration slip — needed for residence permit
