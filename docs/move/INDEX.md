## Quick path reminder

1. Confirm passport has **6+ months** validity remaining.  
2. Order **sealed ITT transcripts** (Parchment) → notarize / authenticate → **TN apostille**.  
3. Get **FBI Identity History Summary** (EDO) → **TN apostille** (or Dept. of State if required for that doc).  
4. Finish **CELTA**, land language-center offer, employer issues **Work Permit Notification / PU letter**.  
5. Assemble **Z visa** stack (Embassy DC).  
6. Fly Guangzhou → medical → residence permit (CAN) with Coco’s help on address registration.

*Templates only — not official government forms. Always re-check current embassy / SOS / FBI instructions before mailing.*
