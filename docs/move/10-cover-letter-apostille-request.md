# 10 — Cover Letter Template: TN SOS Apostille Request

Fill blanks, print, and include with your Tennessee Secretary of State apostille packet.  
Official guide: https://sos.tn.gov/businesses/guides/apostille-authentication-guide  

**This is a personal cover letter template — not an official SOS form.** Attach whatever request form / payment the SOS guide currently requires.

## Reminder

- Education docs notarized in **Tennessee** → TN SOS apostille (this letter).  
- **FBI** Identity History Summary is usually a **federal** authentication path — do not put FBI-only docs in this TN packet unless SOS explicitly accepts them (they typically do not). See `05-fbi-edo-checklist.md`.
