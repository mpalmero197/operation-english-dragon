# 06 — Z Visa Document Stack (ordered)

**Apply only after** you have a **Work Permit Notification / PU invitation** from the Chinese employer.  
**Jurisdiction:** Tennessee resident → **Chinese Embassy Washington, DC**.

---

## Official links (re-check before every submission)

| Resource | URL |
|----------|-----|
| China visa COVA / consular portal | http://consular.mfa.gov.cn/VISA/ |

Always read the **latest** embassy notice; requirements change.

---

## Ordered stack (top → bottom for folder)

Assemble in this order so nothing is missing at the window / mailer:

1. [ ] **Passport** (original) — 6+ months validity, blank visa pages  
2. [ ] **Passport bio page** photocopy  
3. [ ] **COVA** online form confirmation / printed application (complete, signed as required)  
4. [ ] **Visa photo(s)** meeting China specs — `07-photo-specs.md`  
5. [ ] **Work Permit Notification / PU letter** (original or as embassy specifies) + copy  
6. [ ] **Employment contract / offer** (signed) + copy  
7. [ ] **Degree** with **apostille** (ITT bachelor’s path) + copy  
8. [ ] **Transcripts** (sealed / apostilled as required) + copy  
9. [ ] **FBI Identity History Summary** with **authentication/apostille** + copy  
10. [ ] **CELTA certificate** + copy (if listed by employer / embassy pack)  
11. [ ] **Proof of legal stay / ID** if requested (TN address evidence)  
12. [ ] **Visa fee** payment per current embassy instructions  
13. [ ] **Appointment confirmation** / submission receipt  
14. [ ] Any **supplementary forms** listed on the current DC embassy notice

## Process sketch

1. [ ] Employer in China obtains Work Permit Notification / PU  
2. [ ] They send you the invitation documents (scan first, originals if required)  
3. [ ] Complete COVA at the consular visa site  
4. [ ] Confirm DC jurisdiction for Tennessee  
5. [ ] Book / follow current submission method (appointment, mail, or CVASC if applicable — **follow current notice**)  
6. [ ] Submit ordered stack  
7. [ ] Retain pickup / return tracking  
8. [ ] Verify visa sticker: name, passport #, entries, validity, “Z” type  

---

## Common rejection risks

- Name mismatch (passport vs COVA vs invitation)  
- Photo wrong size / background / glasses glare  
- Expired police check  
- Missing apostille  
- Wrong consular jurisdiction  
- Applying before PU / notification is issued
