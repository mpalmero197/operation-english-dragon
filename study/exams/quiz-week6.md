# Week 6 Checkpoint Quiz — Lesson Planning

**Lesson:** [07-lesson-planning](../lessons/07-lesson-planning.md) · **Qs:** 16

---

## Questions

**1.** Rewrite as a SMART-ish CELTA aim: *Teach vocabulary of hotels.*  
**2.** Main vs subsidiary vs personal aim — one-line each.  
**3.** Name four columns you’d expect in a procedure table.  
**4.** PPP stands for…?  
**5.** Why context before the rule (usually)?  
**6.** Interaction pattern codes: PW, GW, T–S — expand.  
**7.** Anticipated problem + solution for teaching *for* vs *since*.  
**8.** MCQ: Vague aim: A. *Learners will better ask for directions using imperatives and prepositions of place* B. *Do speaking* C. *Practise scanning station signs for platform numbers*  
**9.** Copyright-aware adaptation — one good practice.  
**10.** When might Test–Teach–Test help?  
**11.** Skills lesson: why gist before detail?  
**12.** List three items in a class profile on a plan.  
**13.** Timing tip: controlled practice overruns — what cut first?  
**14.** Materials “professional appearance” means…?  
**15.** Evaluate: 25-min teacher explanation then 5-min pair work for a “speaking” lesson — issue?  
**16.** Write a miniature 4-stage outline (names only) for a listening lesson.

---

## Answer key

**1.** Example: *By the end, learners will better understand and use 8 hotel nouns in a check-in role-play.*  
**2.** Main = primary learner outcome; subsidiary = supporting; personal = teacher skill focus.  
**3.** Stage, aim, procedure, interaction, timing (any four).  
**4.** Present, Practice, Produce.  
**5.** Meaning/use clearer; engagement; aids discovery.  
**6.** Pair work; group work; teacher–student(s).  
**7.** Confusion of point vs period → timelines + CCQs.  
**8.** B is vague (A and C are clearer).  
**9.** Don’t copy entire books; credit sources; use allowed excerpts; create original worksheets.  
**10.** Diagnosing what they already know; revision.  
**11.** Global understanding first; reduces overload.  
**12.** Level, L1s, needs, size, constraints…  
**13.** Trim teacher talk / optional extras; protect freer stage if it’s the aim.  
**14.** Clear, legible, organised handouts/slides; learner-friendly layout.  
**15.** Excess TTT; insufficient STT for stated aim.  
**16.** Lead-in → pre-teach → gist → detail (→ follow-up).
