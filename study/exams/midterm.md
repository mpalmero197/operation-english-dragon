## Answer key / mark guidance

**A1.** Expect L1 mix, level, schedule, goals, dyslexia support notes (fonts, extra processing time, oral options).  
**A2.** Instrumental → exam/job authentic tasks; integrative → community/culture interaction, etc.  
**A3.** Facilitator; informer; monitor; facilitator/feedback.  
**A4.** Consistent productive model + receptive awareness; intelligibility; respect learner goals.  

**B1.** Recent completed action with present relevance (*just*); *has/have + just + PP*; /ʃiːz/ linking; problems: *just* + past simple only; CCQs on “now finished?”, “recently?”, “do we know exact clock time?”  
**B2.** Prohibition vs no obligation — see Lesson 02.  
**B3.** Pause from work; *take + a + break*; not *make a break*; CCQs on resting.  
**B4.** Content stress on *want/do/tonight*; weak *do/you/to*.  

**C1.** Lead-in → pre-teach → gist (why called?) → detail (new time/place) → follow-up diary speak.  
**C2.** Skim/scan/detail as labelled.  
**C3.** Lexis density → glossary; culture refs → prediction images.  
**C4.** Practises subskills + task design rationale.  

**D1.** Too hard detail first listen; vocab; memory load → second listen with options; pre-teach; note-taking scaffold.  
**D2.** Knowledge/staging/analysis can improve; cannot replace assessed TP, real learners, tutor feedback, certificate.
