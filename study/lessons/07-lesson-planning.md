## Learning aims

1. Write clear main and subsidiary aims  
2. Stage lessons logically with timing and interaction patterns  
3. Analyse language/skills on the plan; anticipate problems + solutions  
4. Select/adapt materials responsibly (including copyright awareness)

---

## Core concepts

### Why plan?
Planning clarifies aims, reduces chaos, helps tutors support you, and builds reflection habits. On CELTA, the plan is assessed alongside teaching.

### What a CELTA-style plan usually includes
- Class profile · Learner outcomes / aims · Personal aims  
- Assumptions · Anticipated problems + solutions  
- Materials · Language analysis (if language lesson) or skills focus  
- Procedure table: stage name, aim of stage, procedure, interaction (T–S, S–S, GW…), timing  

### Aims that work
- **Main aim:** what learners will be better able to do by the end  
  - Language: *By the end of the lesson, learners will be better able to talk about life experiences using present perfect with “ever/never”.*  
  - Skills: *…better able to skim online reviews for overall opinion.*  
- **Subsidiary aim:** supporting focus (e.g. vocabulary for the task; fluency)  
- Avoid vague aims: *teach past simple* / *do page 42*

### Common shapes (overview, not dogma)
| Shape | Rough flow | Good for |
|-------|------------|----------|
| **PPP** | Present → Practice → Produce | Straightforward systems lessons |
| **Skills** | Lead-in → gist → detail → follow-up | R/L lessons |
| **TBL** | Task → planning/report → language focus | Task-driven lessons |
| **Test–teach–test** | Diagnose → clarify → re-try | Revision / mixed levels |

Logical order beats fashionable labels: context before rules; gist before detail; clarification before freer use of new forms.

### Materials & resources
Coursebook, authentic texts, board, realia, phones, slides, LMS. **Adapt** for level, culture, time, and aims. Respect copyright; don’t photocopy whole books illegally. Low-resource teaching is a skill — board + paper can be excellent.

### Evaluating plans
Before: Will this achieve the aim? Enough learner talking time? After: What will I change next time?

## Key terminology glossary

| Term | Definition |
|------|------------|
| **Main aim / learning outcome** | Primary intended learner achievement |
| **Subsidiary aim** | Secondary supporting aim |
| **Personal aim** | Teacher development focus (e.g. reduce TTT) |
| **Interaction pattern** | Who talks to whom (T–S, PW, GW, IW) |
| **TTT / STT** | Teacher talking time / student talking time |
| **Staging** | Ordered phases of the lesson |
| **Anticipated problems** | Predicted language/task/learner difficulties |
| **Assumptions** | What you believe learners already know |
| **Warmer / lead-in** | Opening to engage / activate schema |
| **Controlled / freer practice** | Restricted accuracy work vs freer use |
| **Adaptation** | Changing materials to fit learners/aims |
| **Pacing** | Speed and timing of stages |

## Worked example (original mini plan outline)

**Level:** A2 · **Time:** 45 min · **Main aim:** Request food in a café using *I’d like…* / *Can I have…?*  
**Subsidiary:** Pronunciation of polite intonation; café lexis (*still water*, *bill*).  

| Stage | Aim | Interaction | Time |
|-------|-----|-------------|------|
| Lead-in photos | Activate café schema | T–S, PW | 5 |
| Lexis match | Blocking vocab | PW | 6 |
| Clarify TL | MFP of requests | T–S | 8 |
| Controlled dialogue | Accuracy | PW | 8 |
| Role-play café | Freer use | PW | 12 |
| Feedback | Upgrade language | T–S | 6 |

**Anticipated problem:** Learners use *I want* only. **Solution:** Contrast politeness; drill *I’d like*; delayed feedback upgrade.

## Practice tasks

**Task 1.** Rewrite as a proper aim: *Do listening on page 19.*  
**Task 2.** For a present continuous “arrangements” lesson, list 3 anticipated problems + solutions.  
**Task 3.** Label interaction: teacher explains rule to class; learners check answers in pairs; groups create a poster.  
**Task 4.** You have a dense newspaper paragraph for B1. Describe two adaptations.

## On the real CELTA
Planning criteria (publicly summarised) include stating aims, ordering activities, materials appearance/copyright, detailed procedures, interaction, timing, language analysis, anticipating problems, skills terminology, teamwork, and reflecting on plans. Tutors prefer realistic timing and clear stage aims.
