# Lesson 06 — Productive Skills (Speaking & Writing)

## Learning aims

1. Distinguish fluency-focused vs accuracy-focused speaking work  
2. Use functional language and task design for meaningful speaking  
3. Stage process writing (and know product approaches)  
4. Give feedback that develops skills without crushing confidence

---

## Core concepts

### Speaking
**Features of spoken English:** shorter turns, interruptions, fillers (*um*, *you know*), unfinished sentences, gestures (paralinguistics).

| Focus | Aim | Example |
|-------|-----|---------|
| **Fluency** | Keep communicating | Timed discussion; ranking task |
| **Accuracy** | Notice/get form right | Drill → controlled dialogue |
| **Functions** | Do things with language | Suggesting, disagreeing politely, requesting |

**Task types:** information gap, opinion gap, ranking, role-play, problem-solving. Provide **preparation time** and useful phrases.

**Feedback:** immediate (if accuracy aim) vs delayed/board-based (if fluency aim).

### Writing
**Subskills:** organising ideas, paragraphing, cohesion, genre features, spelling, punctuation, drafting/editing.

**Process approach stages (typical):** generate ideas → plan → draft → peer/tutor feedback → redraft → proofread.  
**Product approach:** model text → analyse features → write similar text.

**Adult literacy:** respect learners new to Roman script; teach handwriting/keyboard as needed.

## Key terminology glossary

| Term | Definition |
|------|------------|
| **Productive skills** | Speaking and writing |
| **Fluency** | Ease and flow of communication |
| **Accuracy** | Correctness of language |
| **Function** | Communicative purpose (e.g. apologising) |
| **Exponents** | Language forms that realise a function |
| **Information gap** | Speakers need to exchange unknown info |
| **Turn-taking** | Managing who speaks when |
| **Cohesion / coherence** | Links in text / overall sense |
| **Process writing** | Emphasis on drafting stages |
| **Genre** | Text type with shared features (email, review) |
| **Peer feedback** | Learners respond to each other’s work |
| **Paralinguistic features** | Gesture, facial expression, eye contact |

## Worked examples (original)

### Speaking (B1) — polite requests
Lead-in: annoying flatmate situations. Clarify exponents: *Would you mind + -ing…?* Controlled: match situations to phrases. Freer: role-play flatmates. Delayed feedback: board 3 improved phrases.

### Writing (B1) — apology email
Model email → notice greeting, reason, offer, closing → plan own scenario → draft → peer checklist (greeting? reason? offer?) → improve.

## Practice tasks

**Task 1.** Fluency or accuracy focus? (a) Drill of *Have you ever…?* (b) 4-minute free chat about travel with no interruption.  
**Task 2.** List three exponents for *making suggestions*.  
**Task 3.** Order process-writing stages: redraft; brainstorm; peer feedback; first draft; proofread.  
**Task 4.** Design a simple peer checklist (4 items) for a short restaurant review.

## On the real CELTA
TP criteria include helping learners produce spoken/written language and develop writing. Balance teacher talk with learner talk. Writing lessons need a clear genre/aim, not “write anything for 20 minutes” without support.
