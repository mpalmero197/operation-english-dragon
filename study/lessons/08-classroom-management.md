## Learning aims

1. Organise whole-class, pair, group, and individual work efficiently  
2. Give clear instructions and check them (ICQs)  
3. Monitor usefully and manage pace/rapport  
4. Adjust teacher language to the level

---

## Core concepts

### Organisation & presence
- Arrange space (or breakout rooms) for the task; safety first  
- Start/finish on time; signal transitions  
- Build rapport: learn names, fairness, humour without sarcasm  

### Instructions that work
1. Get attention  
2. Keep language simple; show as well as tell (demo)  
3. Give instructions **before** handing out papers when possible  
4. **ICQs** (Instruction Checking Questions) — not “Do you understand?”  
5. Let them start; monitor the first 20 seconds for confusion  

**ICQ examples:** Are you writing or speaking? *(Speaking)* Do you talk to one partner or the whole group? *(One partner)* How many minutes? *(Three)*

### Monitoring
Listen for task success *and* language; note errors for feedback; avoid hovering intimidatingly; support quietly.

### Teacher language
Grade your language; avoid unnecessary metalanguage at low levels; use L1 only if policy/need supports it.

### Pace & variety
Alternate intensity; don’t let controlled practice die of boredom or freer tasks collapse from under-instruction.

### Levels & differentiation
Same task, different support (sentence stems, roles); peer pairing strategies; extension questions for early finishers.

## Key terminology glossary

| Term | Definition |
|------|------------|
| **ICQ** | Instruction Checking Question |
| **Rapport** | Positive teacher–learner relationship |
| **Monitoring** | Observing/supporting during tasks |
| **Grouping** | Pair/group decisions |
| **Demo / model the task** | Show what to do |
| **TTT** | Teacher talking time |
| **Transition** | Moving between stages |
| **Differentiation** | Adapting challenge/support within one class |
| **Whole-class feedback** | Sharing answers/ideas after a task |
| **Online breakout** | Separate virtual rooms for pair/group work |

## Worked examples (original)

**Weak instruction:** “OK so basically you’re going to like discuss maybe in pairs or whatever the questions if you want.”  
**Stronger:** “Work in pairs. Ask your partner questions 1–4. You have four minutes. → ICQs: Alone or together? *(Together)* Writing the answers or only speaking? *(Speaking)*.”

**Monitoring note sheet:** columns for Good language / Needs work / Task issues — feeds delayed feedback.

---

## Practice tasks

**Task 1.** Write 3 ICQs for: learners mingle to find someone who has done four listed experiences.  
**Task 2.** Two problems with seating all learners in rows for a debate — and a fix.  
**Task 3.** Grade this teacher sentence for A1: *“I’d appreciate it if you could possibly complete the handout collaboratively.”*  
**Task 4.** Early finishers done 5 minutes early in pair practice — give two useful options.

## Answer key

**Task 1.** Examples: Do you sit or stand/walk? *(Mingle/walk)* Do you ask one person only or several? *(Several)* Do you write full sentences? *(Notes/ticks only — as designed)*.  

**Task 2.** Hard to face interlocutors; uneven participation — use horseshoe/groups or standing debate lines.  

**Task 3.** Example: *Work with a partner. Finish the paper together.*  

**Task 4.** Swap partners; add two extra questions; write two sentences using TL; peer-check spelling — any on-aim extensions.
