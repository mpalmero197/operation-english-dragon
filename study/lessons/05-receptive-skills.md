# Lesson 05 — Receptive Skills (Reading & Listening)

## Learning aims

1. Name reading/listening subskills and match tasks to them  
2. Stage a receptive lesson: lead-in → pre-teach (if needed) → gist → detail → follow-up  
3. Identify barriers and design support  
4. Connect task design to the *Language skills related tasks* assignment

---

## Core concepts

### Reading subskills (teaching labels)
| Subskill | Purpose | Typical task |
|----------|---------|--------------|
| **Skimming** | Gist / overall idea | Match title; choose summary |
| **Scanning** | Find specific info | Times, names, prices |
| **Reading for detail** | Careful understanding | True/False/Not Given; WH questions |
| **Inferring** | Read between lines | Attitude; pronoun reference |
| **Deducing meaning from context** | Unknown lexis | Guess meaning from co-text |

### Listening subskills
Gist; specific information; detail; inferring attitude; listening for features (e.g. invitations). Spoken texts include hesitations, overlaps, weak forms — prepare learners.

### Purposes
We read/listen differently for exam practice, pleasure, instructions, news — tasks should reflect purpose.

### Barriers
Unknown lexis/grammar; cultural references; speed; accents; noise; dense noun phrases; lack of schema. Support with images, prediction, glossaries, replay, scaffolding questions.

### Staging (classic skills shape)
1. **Lead-in / schema** — interest + prediction  
2. **Pre-teach** only blocking vocabulary  
3. **Gist** task (short, global)  
4. **Detail / specific info** task  
5. **Follow-up** — speaking/writing that uses the content  
6. Optional language focus from the text  

Never start with forensic detail questions before gist — learners drown.

## Key terminology glossary

| Term | Definition |
|------|------------|
| **Receptive skills** | Reading and listening |
| **Gist** | General understanding |
| **Schema** | Background knowledge brought to a text |
| **Authentic text** | Not written for language learners (may be graded/adapted) |
| **Graded reader / simplified text** | Language controlled for level |
| **Top-down / bottom-up** | Knowledge-driven vs decoding sounds/letters upward |
| **Blocking vocabulary** | Words without which the task fails |
| **While-listening / while-reading** | Tasks done during the skill |
| **Follow-up** | Post-text productive work |
| **Subskill** | Specific skill focus within reading/listening |

## Worked examples (original)

### Reading — café review (B1)
Lead-in: favourite cafés. Pre-teach: *queue*, *flat white*. Gist: Is the review mainly positive or negative? Detail: What did the writer order? How long was the wait? Follow-up: write a 3-sentence review of a local place.

### Listening — voicemail (A2/B1)
Gist: Why did Maya call? Detail: time, place, what to bring. Barrier support: play twice; give options (multiple choice) not open write-all-first-time.

## Practice tasks

**Task 1.** Label each task skimming, scanning, or detail: (a) Find the phone number. (b) Choose the best headline. (c) Explain why the writer was disappointed.  
**Task 2.** Order stages for a listening lesson (jumbled): detail Qs; lead-in; gist; follow-up discussion; pre-teach 3 words.  
**Task 3.** Name two barriers for learners listening to fast native-speaker YouTube, and one support each.  
**Task 4.** Invent one gist and one detail question for a short notice: *Library closed Saturday 14 Sept for staff training. Reopens Sunday 10:00.*

## On the real CELTA
Skills TP is judged on helping learners understand texts (criteria 3a). Assignment 3 asks you to identify subskills and design tasks with rationale. Avoid “read the text and answer 12 random questions” without staging.

## Answer key

**Task 1.** (a) scanning (b) skimming (c) detail/inference (detail acceptable if focused on careful reading).  
**Task 2.** Lead-in → pre-teach → gist → detail → follow-up.  
**Task 3.** Examples: speed → slower replay/transcript later; unknown slang → pre-teach/glossary; accent → prediction + second listen with support.  
**Task 4.** Gist: Is the library open this Saturday? Detail: What time does it reopen on Sunday?
