## Learning aims

1. Classify errors (slip vs systematic error; categories)  
2. Choose *whether*, *when*, and *how* to correct  
3. Write effective CCQs for grammar and lexis  
4. Use elicitation and questioning without leading blindly

---

## Core concepts

### Errors vs slips
- **Slip:** learner can self-correct; fatigue/attention  
- **Error:** gap in knowledge/system — needs teaching/noticing  

### Categories (practical)
Grammar · Lexis · Pronunciation · Appropriacy/register · Task misunderstanding (not “language error”)

### Whether / when / how
| Situation | Tendency |
|-----------|----------|
| Fluency speaking aim | Delayed, selective, board-based |
| Accuracy practice / drills | Gentler immediate correction |
| Confidence-building shy learner | Soften; peer support; praise message |
| Fossilised error blocking aim | Focused feedback + practice |

**Techniques:** finger correction; prompt (*Tense?*); recast; delayed board; peer correction; reformulation; sound/stress gestures.

### CCQs — concept checking
Good CCQs:
- Check **meaning**, not whether they heard the rule  
- Are answerable simply (yes/no, this/that, one-word)  
- Fail if the learner misunderstood  

Avoid: *Do you understand?* · *What is the present perfect?* (too meta) · repeating the target structure as the only “check”

### Elicitation
Ask for what learners may know; don’t play “guess what’s in my head” for too long — provide the language if elicitation stalls.

## Key terminology glossary

| Term | Definition |
|------|------------|
| **CCQ** | Concept Checking Question |
| **ICQ** | Instruction Checking Question (different!) |
| **Recast** | Reformulate learner utterance correctly |
| **Delayed correction** | Feedback after the task |
| **Fossilisation** | Persistent error despite exposure |
| **Elicitation** | Drawing language/ideas from learners |
| **Appropriacy** | Social suitability of language |
| **Self-correction** | Learner fixes own output |
| **Peer correction** | Learners correct each other |
| **Time line** | Visual for tense/aspect meaning |

## Worked examples (original)

### CCQs — *He used to live in Lima*
- Does he live in Lima now? *(No)*  
- Was it a long-term situation in the past? *(Yes)*  

### CCQs — *borrow* vs *lend* (*Can I borrow your charger?*)
- Do I want your charger for a short time? *(Yes)*  
- Do you give it to me temporarily? *(Yes)* Who keeps it at the end? *(You/the owner)*  

### Correction choice
Fluency debate; learner: *In my opinion, the government don’t do nothing.*  
→ Note on monitoring pad; after task board: *doesn’t do anything* / double negative awareness — don’t stop the debate mid-flow unless intelligibility collapses.

## Practice tasks

**Task 1.** Write 2–3 CCQs for *She’s going to start a new job on Monday* (prior plan).  
**Task 2.** Write 2 CCQs for lexical item *overpriced*.  
**Task 3.** Learner in controlled practice: *She can sings.* Immediate technique?  
**Task 4.** Separate ICQs from CCQs: label each — (a) “Are you working alone?” (b) “Is the action finished?”

## On the real CELTA
Tutors watch correction sensitivity and clarity of concept checking (criteria on identifying/correcting errors; clarifying meaning/form; effective questions). Over-correcting fluency tasks and under-checking concepts are common trainee issues.
